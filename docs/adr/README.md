# Architecture decisions

Short records of the decisions that gave this package its shape, each with the reasoning that was
available at the time. They are not updated when the code moves on; a decision that is reversed gets
a new record that supersedes the old one.

| --- | --- |

| [3](0003-configuration-is-generated-by-the-package.md) | The runtime configuration is generated by the package, not read from the repository under review |
| [4](0004-no-dependencies-manifests-in-json.md) | No npm dependencies, and manifests in JSON rather than YAML |
| [5](0005-keeping-the-opencode-github-action.md) | The runtime is invoked through the OpenCode GitHub action, not the CLI |
| [6](0006-english-by-default.md) | Agents write in English by default, and the operator can override it |
| [7](0007-what-is-deliberately-not-in-the-first-release.md) | What is deliberately not in the first release |
